# LUXÉO PERFUMES — Luxury Haute Parfumerie Website

A luxury perfume e-commerce web application built with **Next.js 15+ (App Router)**, **TypeScript**, **Tailwind CSS**, and **GSAP Animations**.

## 🌟 Key Features

- **Editorial Hero Section**: Full-bleed luxury aesthetic with GSAP entrance timeline and parallax scroll effects.
- **Animated Luxury Preloader**: Monogram entrance animation with real-time loading counter and curtain-lift reveal.
- **Product Collection & Carousel**: Interactive swipeable carousel with quick-add to bag, size selectors (50ml / 100ml), and price recalculations.
- **Interactive Olfactory Pyramid Explorer**: Multi-stage fragrance pyramid breakdown (Top, Heart, and Base notes).
- **Full E-Commerce Flow**: Interactive Cart Drawer with live item increment/decrement, free shipping progress bar, promo code engine, and checkout modal.
- **Quick View Modal**: Deep-dive product preview with accords, longevity ratings, and sensory notes.
- **Brand Story Video Experience**: Cinematic brand storytelling modal.
- **100% Mobile Responsive**: Customized adaptive layout designed specifically for mobile and desktop screens.
- **Typography Architecture**: Cormorant Garamond for luxury serif editorial headings and Manrope for modern UI elements.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP & GSAP ScrollTrigger
- **Icons**: Lucide React
- **Fonts**: Cormorant Garamond & Manrope via `next/font/google`

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open in browser
http://localhost:3000
```

## 📦 Production Build

```bash
npm run build
npm start
```
